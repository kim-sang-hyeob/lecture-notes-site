R5-09객관식

[A] 상사는 팀장에게 구성원에게 결정권을 전부 맡기라고 요구하지만, 구성원은 팀장이 매번 직접 결정해 주기를 요구한다. [B] 직장은 늦게까지 일하기를 요구하고 가족은 같은 시간에 돌봄에 참여하기를 기대한다. 두 사례를 구별한 것은?

  1. 1. A: 직장과 가정의 역할 간 갈등(inter-role conflict) / B: 직장 안의 역할 기대 상충
  2. 2. A: 직장 안의 역할 기대 상충 / B: 직장과 가정의 역할 간 갈등(inter-role conflict)
  3. 3. A와 B 모두 직장 안에서만 일어난 역할 기대 상충
  4. 4. A와 B 모두 직장과 가정 사이의 역할 간 갈등(inter-role conflict)

R5-10객관식

팀장 A는 직장에서 배운 경청·피드백·갈등관리 기술을 배우자와 대화할 때 활용해 다툼을 해결했다. 이 사례에 대한 설명으로 가장 적절한 것은?

  1. 1. 같은 기술을 사용했으므로 직장과 가정의 기대 행동도 언제나 같다는 뜻이다.
  2. 2. 직장 경험은 가정에 부담만 주므로 이 사례도 반드시 갈등이다.
  3. 3. 직장에서 얻은 기술을 가정의 관계에 활용하여 다른 역할 수행을 도운 것이다.
  4. 4. 일에서 익힌 기술은 가정이라는 다른 영역에서 자원이 될 수 없다.

R5-11객관식

퇴근하자마자 가정의 요구를 받으면 회사에서의 긴장을 그대로 드러내던 직원이, 이동 중 마음을 정리한 뒤 가족과 대화하기 시작했다. 가장 직접적인 해석은?

  1. 1. 역할전환(Role Transition)에 도움이 되었다면 통근(Commuting)의 시간·에너지 비용은 존재하지 않는다.
  2. 2. 직장의 기대 행동을 가정에서도 그대로 유지하는 것이 회복이다.
  3. 3. 통근(Commuting)은 길이에 비례해 모든 사람의 건강을 높인다.
  4. 4. 이동 시간이 두 역할 사이의 완충 공간으로 활용된 사례이다.

R5-12객관식

하루 근무시간을 늘려 근무일을 줄이는 일정을 평가할 때 가장 부적절한 것은?

  1. 1. 긴 연속 휴일의 장점과 하루에 집중되는 부담을 함께 본다.
  2. 2. 쉬는 날이 늘면 하루의 체력 부담은 따로 평가할 필요가 없다.
  3. 3. 하루의 의무 근무시간이 길어질 때 유연성이 줄 수 있음을 살핀다.
  4. 4. 같은 사람도 체력과 생활 조건이 달라지면 선호가 달라질 수 있다.

R5-13객관식

아픈 직원이 “내가 빠지면 일이 멈춘다”며 출근했지만 업무의 질이 떨어지고 동료도 부담을 느낀다. 가장 적절한 대응 관점은?

  1. 1. 부재의 영향을 크게 보는 믿음과 건강·생산성 비용을 함께 검토한다.
  2. 2. 책임감이 동기라면 행동의 결과도 반드시 긍정적이라고 본다.
  3. 3. 출근했으므로 개인 건강과 조직 생산성은 모두 개선되었다고 본다.
  4. 4. 실제 출근 여부만으로 회복 필요와 조직의 비용을 판단한다.

R5-14객관식

원격근무(Telework)로 직원들이 각자 산출물을 내고 있지만, 신입이 동료와 자연스럽게 대화하며 조직문화를 익힐 기회는 줄었다. 이에 대한 판단으로 가장 적절한 것은?

  1. 1. 서로 다른 공간에서 일하면 모든 협업이 반드시 불가능하다.
  2. 2. 산출물만 충족하면 조직문화와 사회화 과정은 자동 유지된다.
  3. 3. 신입 사회화는 개인이 혼자 익혀야 하므로 조직 운영과 무관하다.
  4. 4. 개별 산출물 외에 소통·협업·신입 사회화의 조건도 살펴야 한다.

R5-15객관식

참가자를 무작위로 두 집단에 배정하고 한 집단에만 처치를 한 뒤 결과를 비교했다. 이 실험설계의 강점과 한계를 바르게 설명한 것은?

  1. 1. 인과 해석을 돕지만 다른 현실 상황에도 결과가 나타나는지는 따로 검토한다.
  2. 2. 무작위 배정은 관찰된 관련을 크게 만드는 기법이므로 효과크기만 보면 된다.
  3. 3. 강점은 모든 현실 상황의 대표성이고, 인과 해석은 원래 불가능하다.
  4. 4. 무작위 배정만 하면 처치를 하지 않아도 같은 인과적 결론을 얻는다.

R5-16객관식

직원이 “근무 장소를 선택하고 싶지만 동료와 직접 만나는 시간도 늘었으면 좋겠다”고 한다. 이 두 요구를 파악하기 위한 조사 방법으로 가장 적절한 것은?

  1. 1. 재택 선호로 답했으면 대면 욕구는 없다고 코딩한다.
  2. 2. 장소 선택의 유연성과 대면 연결의 욕구를 별도로 묻는다.
  3. 3. 사무실과 재택 중 하나를 선택하게 하고 다른 요구는 측정하지 않는다.
  4. 4. 두 요구가 함께 나오면 일관성 없는 응답으로 버린다.

R5-17객관식

실업 기간과 심리적 고통의 관계에 대한 설명으로 가장 적절한 것은?

  1. 1. 고통이 계속 직선적으로 증가한다고 가정하지 않되 개인 조건과 구직 상황도 함께 본다.
  2. 2. 처음 고통이 적게 보이면 이후에도 도움이 필요하지 않다.
  3. 3. 실직 기간만 알면 모든 사람의 심리 상태를 정확히 정할 수 있다.
  4. 4. 오래 실직하면 고통이 줄 수 있으므로 실업 지원은 필요 없다.

R5-18객관식

한 사람은 출근 일정이 생활을 정돈해 준다고 느끼지만, 다른 사람은 정시 출근을 부담스럽게 느낀다. 고용의 잠재적 기능(latent functions)에 대한 판단으로 적절한 것은?

  1. 1. 일상에 규칙적인 일과(time structure)가 있다는 사실은 소득 액수와 완전히 같은 변수이다.
  2. 2. 잠재적 기능(latent functions)은 정의상 모든 개인에게 항상 같은 정도로 이롭다.
  3. 3. 고용의 잠재적 이득을 일률적으로 좋은 것으로만 보지 말아야 한다.
  4. 4. 정시 출근이 부담스러우면 고용에는 어떤 긍정적 기능도 없다.
