R2-10객관식

학생이 낮은 만족–수행 상관과 호손 연구(Hawthorne study) 이후의 관심이 충돌하지 않느냐고 물었다. 시장 수요를 예로 든 답변을 가장 잘 보존한 것은?

  1. 1. 만족·동기 외에도 성과를 설명하는 요인이 있으므로 만족 하나에 모든 설명을 맡기면 안 된다.
  2. 2. 개인의 직무수행과 기업 매출은 같은 변인이므로 서로 바꾸어 사용해도 된다.
  3. 3. 시장 수요가 기업 성과에 영향을 주므로 직원 만족은 누구에게나 무의미하다.
  4. 4. 기업 실적이 좋아졌다면 원인은 반드시 그 전에 높아진 직원 만족이다.

R2-11객관식

현재 업무 방식에 불만이 있는 A는 회사의 발전을 바라며 개선안을 낸다. 강의의 창의성 설명과 가장 맞는 판단은?

  1. 1. 회사를 좋아하는 사람은 현재 직무에 불만을 느낄 수 없다.
  2. 2. 조직에는 애착이 있으면서 현재 직무에는 불만족한 조건을 함께 봐야 한다.
  3. 3. 불만족만 있으면 조직에 대한 태도와 무관하게 창의성이 반드시 높아진다.
  4. 4. 아이디어가 나왔으므로 불만족 보고는 거짓이다.

R2-12객관식

보고서를 낸 직원이 다음에 어떻게 개선해야 할지 모른다. Feedback을 강조한 강의에 가장 가까운 상사의 대응은?

  1. 1. 다음 행동은 알려주지 않고 점수만 아주 늦게 전달한다.
  2. 2. 아무 말도 하지 않아 평가를 추측하게 한다.
  3. 3. 기준 없이 사람 자체를 깎아내리는 말만 한다.
  4. 4. 개선점을 즉각적·건설적·유용하게 알려 다음 행동의 설계를 돕는다.

R2-13객관식

  4. 4. A는 일정 구조, B는 개인의 자기 효능감(self-efficacy)만을 바꾼다.

R2-14객관식

같은 전문직인 A와 B가 다른 조직에 속해 있다. 교수님의 대학 간 자율성(autonomy) 비교를 바탕으로 적절한 조사 계획은?

  1. 1. 개인의 급여만으로 자율성(autonomy)을 판단한다.
  2. 2. 직업명이 같으므로 자율성(autonomy)도 같다고 입력한다.
  3. 3. 각 조직이 실제로 허용하는 판단·일정·수행방식의 재량을 확인한다.
  4. 4. 조직 차이는 존재할 수 없으므로 성격만 조사한다.

R2-15객관식

오래 충성하면 안정적으로 고용될 것이라 믿은 직원이 인력 감축 발표에 배신감을 느낀다. 이를 심리적 계약(psychological contract)과 연결한 핵심 이유는?

  1. 1. 인력 감축은 고용관계 기대와 무관하기 때문이다.
  2. 2. 자신의 기여에 상응하는 지속적 고용의 암묵적 기대와 조직 대응이 충돌할 수 있기 때문이다.
  3. 3. 조직에 기여한 적이 없을 때만 심리적 계약(psychological contract)이 생기기 때문이다.
  4. 4. 인력 감축이라는 이름만으로 모든 법적 계약 위반이 입증되기 때문이다.

R2-16객관식

낮은 POS를 조직이 나에게 해 주는 것이 없다는 인식으로 설명하며 심리적 계약(psychological contract)과 연결했다. 적절한 이해는?

  1. 1. 서로 관련될 수 있지만 출발점과 정의까지 같다는 뜻은 아니다.
  2. 2. 낮은 POS는 법적 계약 위반을 반드시 뜻한다.
  3. 3. 두 척도의 문항은 모두 동일해야 한다.
  4. 4. 지원 지각은 상호 기대의 이행과 아무 관련도 없다.

R2-17객관식

강의의 서비스직 사례를 새 상황에 적용한다. 직원이 서비스 대상자를 고유한 사람보다 처리할 물건처럼 대하기 시작했다. 가장 직접적인 단서는?

  1. 1. 업무 자율성(autonomy) 확대
  2. 2. 규범적 몰입(Normative commitment)
  3. 3. 이직 대안 부족
  4. 4. 비인격화(depersonalization)

R2-18객관식

좋은 리더는 Job resources인데 Leadership training을 별도 개입 유형으로 두었으니 모순이라는 해석에 적절한 답은?

  1. 1. 별도 유형이라는 사실은 다른 유형보다 효과가 반드시 높다는 뜻이다.
  2. 2. Leadership training은 업무열의(work engagement)와 관계없는 처치다.
  3. 3. 리더가 제공하는 자원의 의미와 연구가 개입을 묶는 유형을 구별해야 한다.
  4. 4. 별도 유형이면 좋은 리더는 자원일 수 없다.

R2-21단답형

강의에서 결근을 일시적으로, 이직을 더 지속적으로 조직에서 빠져나가는 행동으로 비교했다. 이 둘을 묶어 부른 상위 개념을 쓰시오.

R2-22단답형

업무열의(work engagement)를 높이는 개입 연구를 소개하기 전에, 이미 수행된 여러 연구 결과를 모아 종합하는 방법으로 설명한 분석 명칭을 쓰시오.

R2-23단답형

업무열의(work engagement)를 높이기 위해 교육이나 다른 조치를 실시하는 것을 강의에서 ‘개입’이라고 번역했다. 해당 영어 용어를 쓰시오.

R2-24단답형
