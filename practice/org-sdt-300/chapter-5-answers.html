E5-12객관식

Work–life balance를 가장 잘 설명한 것은?

  1. 1. 자신의 가치와 우선순위에 맞게 일과 비일의 역할을 만족스럽게 수행하는 것
  2. 2. 일과 가족에게 동일한 시간을 배분하는 것
  3. 3. 직장 역할의 요구를 비일 역할보다 우선하는 것
  4. 4. 직장과 가정 사이의 상호작용을 차단하는 것

정답: 1번 · 자신의 가치와 우선순위에 맞게 일과 비일의 역할을 만족스럽게 수행하는 것

WLB는 개인의 가치·우선순위와 만족스러운 역할 수행을 함께 고려한다. Nonwork에는 가족 외에 여가·건강·친구 관계 등도 포함된다.

  1. 가치·우선순위 및 역할 수행이라는 핵심을 포함한다.
  2. 동일한 시간 배분은 WLB의 필수 조건이 아니다.
  3. 한 역할의 우선순위를 일률적으로 정하는 정의가 아니다.
  4. 상호작용의 차단은 Segmentation에 가까운 설명이다.

조직심리학 5장 2쪽 · Work–life balance

E5-13객관식

Greenhaus와 Beutell의 Work–family conflict 유형에 포함되지 않는 것은?

  1. 1. Behavior-based conflict
  2. 2. Time-based conflict
  3. 3. Strain-based conflict
  4. 4. Relationship conflict

정답: 4번 · Relationship conflict

세 유형은 시간의 부족, 한 역할에서 생긴 긴장, 두 역할 사이의 행동 기대 불일치를 기준으로 구분한다. Relationship conflict는 이 세 유형의 명칭이 아니다.

  1. 역할 사이에서 요구하는 행동이 양립하지 않는다.
  2. 한 역할에 쓴 시간이 다른 역할의 참여를 방해한다.
  3. 한 역할의 긴장이 다른 역할 수행을 방해한다.
  4. WFC의 세 유형 목록에 속하지 않는다.

근거: PPT · PPT 3쪽 · WFC의 세 유형
조직심리학 5장 3쪽 · WFC의 세 유형

E5-14객관식

가족과의 갈등으로 긴장한 직원이 업무에 집중하지 못한다. 해당하는 것은?

  1. 1. FIW — Behavior-based conflict
  2. 2. WIF — Time-based conflict
  3. 3. FIW — Strain-based conflict
  4. 4. WIF — Strain-based conflict

정답: 3번 · FIW — Strain-based conflict

가정에서 생긴 긴장이 일을 방해하므로 FIW이며, 방해 방식은 Strain-based conflict다.

  1. 역할별 행동 기대의 불일치가 핵심인 사례가 아니다.
  2. 방해의 방향이 반대이고 시간 부족이 핵심도 아니다.
  3. 가정→일 방향과 긴장 기반이라는 두 분류가 모두 맞다.
  4. 긴장 기반은 맞지만 방향이 가정→일이다.

E5-15객관식

직장에서 얻지 못한 만족을 취미생활에서 채우려는 행동을 설명하는 모델은?

  1. 1. Segmentation model
  2. 2. Compensation model
  3. 3. Deprivation theory
  4. 4. Spillover model

정답: 2번 · Compensation model

Compensation은 한 영역의 부족을 다른 영역에서 보충하는 관계다. Spillover는 두 영역의 경험이 비슷해지는 관계를 설명한다.

  1. 두 영역의 독립성을 강조한다.
  2. 다른 영역에서 부족한 만족을 보충한다는 설명이다.
  3. 실업으로 고용의 잠재적 기능을 잃는 과정을 설명한다.
  4. 한 영역의 경험이 다른 영역으로 파급되는 관계다.

장재윤·김혜숙의 공무원 대상 연구 결과에 해당하는 것은?

  2. 2. WFC와 직무관여의 관계는 남성에게 더 크게 나타났다.

정답: 3번 · WFC와 삶의 만족의 관계는 여성에게 더 크게 나타났다.

  2. 해당 결과는 여성에게 영향이 더 컸다.

E5-17객관식

Greenhaus와 Powell이 제시한 Work–family enrichment의 자원에 포함되지 않는 것은?

  1. 1. Role ambiguity
  2. 2. Flexibility
  3. 3. Social capital
  4. 4. Skills and perspectives

정답: 1번 · Role ambiguity

자원 묶음에는 Skills and perspectives, Psychological and physical resources, Social capital, Flexibility, Material resources가 있다. Role ambiguity는 역할 요구가 불명확한 상태다.

  1. 충실화 자원의 다섯 묶음에 포함되지 않는다.
  2. 역할 수행의 시간·속도·장소를 조절할 자원이다.
  3. 관계에서 얻는 정보·영향력에 해당한다.
  4. 지식·관점·인지 및 대인 스킬에 해당한다.

E5-18객관식

업무에서 배운 갈등 해결 기술을 가족 간 의견 조정에 활용하는 것은 어떤 경로에 가장 가까운가?

  1. 1. Spurious crossover
  2. 2. Segmentation
  3. 3. Affective path
  4. 4. Instrumental path

정답: 4번 · Instrumental path

한 역할에서 얻은 스킬을 다른 역할의 수행에 직접 사용하므로 도구적 경로다. 긍정적 정서가 매개되는 정서적 경로와 구별한다.

  1. 공유 스트레스원이 여러 사람에게 영향을 주는 과정이다.
  2. 두 영역을 독립적으로 보는 관점이다.
  3. 긍정적 정서가 다른 역할을 돕는 경로다.
  4. 기술이라는 자원이 다른 역할 수행에 직접 쓰인다.

E5-19객관식

직장 스트레스를 받은 사람이 배우자를 비난하여 배우자도 스트레스를 경험하게 되는 과정은?

  1. 1. Direct crossover
  2. 2. Spurious crossover
  3. 3. Segmentation
  4. 4. Indirect crossover

정답: 4번 · Indirect crossover
