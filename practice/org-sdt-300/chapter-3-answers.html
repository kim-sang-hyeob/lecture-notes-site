  2. 유쾌함과 활성화가 두 축이다.
  3. 정서(emotion)와 기분(mood)은 경험의 종류를 구별하는 개념이다.
  4. 지속 시간은 이 원형모형의 축이 아니다.

E3-16객관식

불쾌함의 방향은 같지만 활성화 수준이 서로 다른 두 정서는?

  3. 둘 다 유쾌·고활성이다.
  4. 둘 다 불쾌하지만 활성화 수준이 다르다.

E3-17객관식

하루 중 여러 시점에 신호를 보내 그 순간의 정서 상태를 반복 측정하는 방법은?

  1. 1. OCQ
  2. 2. 경험표집법(ESM, Experience Sampling Method)
  3. 3. 일기법(Daily Diary Survey)
  4. 4. critical-incident 방법

경험표집법(ESM, Experience Sampling Method)은 일상 속 여러 시점의 현재 경험을 반복 측정한다. 하루를 회고하는 일기법(Daily Diary Survey)과 구별된다.

E3-18객관식

확장과 구축 이론(Broaden and Build Theory)에서 Build에 해당하는 것은?

  1. 1. 순간적으로 가능한 행동의 범위가 넓어지는 것
  2. 2. 타인의 표정을 보고 같은 감정을 느끼는 것
  3. 3. 조직이 요구하는 감정을 실제로 느끼려는 것
  4. 4. 인지적·사회적 자원이 지속적으로 축적되는 것

정답: 4번 · 인지적·사회적 자원이 지속적으로 축적되는 것

Broaden은 순간적인 사고·행동의 가능성을 넓히고, Build는 그 경험으로 지속적인 자원을 형성하는 과정이다.

  1. 사고·행동 범위의 확장은 Broaden이다.
  2. 다른 사람에게 정서가 퍼지는 현상은 정서 전염(emotional contagion)과 연결된다.
  3. 요구되는 내면 감정을 만드는 노력은 내면 행위(deep acting)이다.
  4. Build는 비교적 오래 남는 자원의 형성을 뜻한다.

근거: PPT · PPT 5쪽 · 확장과 구축 이론(Broaden and Build Theory)

E3-19객관식

한 구성원의 정서가 다른 구성원과 팀 전체로 퍼지는 현상은?

  1. 1. Emotional dissonance
  2. 2. Moral licensing
  3. 3. 정서 전염(emotional contagion)
  4. 4. 내면 행위(deep acting)

정답: 3번 · 정서 전염(emotional contagion)

정서 전염(emotional contagion)은 정서가 사람 사이에서 전파되는 현상이다.

  1. 느끼는 감정과 표현하는 감정의 불일치이다.
  2. 선행을 근거로 부정행동을 스스로 허용하는 과정이다.
  3. 개인 간·집단 내 정서의 전파를 뜻한다.
  4. 실제로 느끼는 감정을 표현 규칙에 맞추려는 노력이다.

근거: PPT · PPT 5쪽 · 정서 전염(emotional contagion)
